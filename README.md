# いつもと違う日（仮称）

普段は静かにしていて、**予定が変わったときだけ**、次に必要な持ち物・行動を計算して知らせる Android アプリです。

## できること（最初のバージョン）

- 通常の予定パターン（毎週おなじ / シフトのくり返し）
- 日付ごとの予定変更（ホームの「＋予定変更」、カレンダーから翌月分もまとめて）
- 持ち物・行動の登録
- ルール：「今週最初の／今週最後の／すべての ○○日」に「△△が必要」、当日の朝 or 前日の夜に知らせる
- 予定変更で「いつもと違う日」になった日だけ、理由つきでお知らせ（時刻は設定画面で変更可）
- 「準備した」ボタン

## しくみ

`src/core/engine.ts` が頭脳です。

1. 「予定変更がなかった場合」と「予定変更後」の2通りで、ルールに合う日を計算する
2. 変更後にだけ出てくる日が「いつもと違う日」
3. その日だけ、お知らせを予約する（60日先まで。アプリを開くたびに延長）

例：月曜を休みにすると、「今週最初の出勤日」が月曜→火曜にずれるので、火曜の朝に「作業服・社員証」を知らせます。

## フォルダ

| 場所 | 中身 |
|---|---|
| `src/core/` | 計算部分（画面やスマホに依存しない）とテスト |
| `src/lib/` | 保存（スマホ内のみ）と Android 通知とのつなぎ |
| `src/ui/` | 画面 |
| `android/` | Android アプリ用のプロジェクト（Capacitor で生成） |

## 開発のしかた

```bash
npm install
npm test          # 計算のテスト
npm run dev       # ブラウザで画面を確認（ブラウザでは通知は届きません）
```

## Android に入れる方法

1. GitHub に push すると、GitHub Actions が自動で APK を作ります
2. GitHub のリポジトリ →「Actions」→「Android APK」→ 最新の実行 → 下の「Artifacts」から `itsumo-chigau-debug-apk` をダウンロード（zip を開くと `app-debug.apk`）
3. スマホに APK を移して開き、インストール（「提供元不明のアプリ」の許可を求められたら許可）
4. 起動後「設定」→「通知を許可する」→「テスト通知を送る」で通知が届くか確認

Android Studio がある場合は `npm run android:sync` → `npx cap open android` でも実行できます。

## 通知の注意

- Android 13 以降は、通知の許可が必要です（設定画面から許可）
- Android 12 以降は「時間ぴったりの通知（アラームとリマインダー）」がオフだと、数分おくれることがあります（設定画面からオンにできます）
- 省電力設定が強い機種では、通知が遅れたり届かなかったりすることがあります
